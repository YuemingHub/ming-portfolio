## 2. 五类真人读者测试卡

### 通用规则

- 每位读者独立完成，主持人只读任务，不解释页面内容、不指路。
- 采用“出声思考”：读者说出现在找什么、以为什么、哪里不确定。

### 9.3 本地 DNS 缓存的排查方式

如果本机仍打不开 `www.ymai.me`，先排除本地缓存：

```bash
nslookup www.ymai.me 1.1.1.1
```

预期看到 `www.ymai.me` 是 `ymai.me` 的别名，并与根域名指向同一地址。若公共解析正确而本机仍失败，问题在本机或路由器缓存，不在服务器；换手机蜂窝网络或等待 TTL 过期后再试。
