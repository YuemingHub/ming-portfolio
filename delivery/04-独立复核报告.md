## 1. 复核方法

复核由全新 Agent 上下文执行，主 Agent 不提供自己的结论摘要，也不允许以主 Agent 的说明代替检查。每轮复核都要求：

1. 自行运行 `git rev-parse HEAD`、`git status`、变更统计与仓库体检；
2. 自行打开源码、测试、nginx 配置与交付文档，不只读清单；
3. 对关键断言实际执行一次，能复现的读数必须复现；
4. 区分“实现”“本地跑过”“CI 跑过”“未执行”，不允许把未执行项写成通过；
5. 输出 P0/P1/P2/P3 分级问题与明确结论。

共进行五轮复核：第 1–3 轮为全量检查，第 4 轮针对第三轮修复，第 5 轮只做增量确认。五轮均未修改仓库文件。
