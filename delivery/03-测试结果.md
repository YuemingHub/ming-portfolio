### 2.1 覆盖内容

| 文件 | 覆盖 |
| --- | --- |
| `tests/routes.spec.ts` | 8 条路由：HTTP 200、标题、H1、canonical、图片数量与加载完成、正文背景色、站内链接可访问、锚点存在、console error = 0、failed request = 0。滚动采用逐屏推进，避免懒加载图片被瞬间跳底跳过 |
| `tests/a11y.spec.ts` | 8 条路由跑 axe，标签 `wcag2a` + `wcag2aa`；违规必须为空，且通过项数 > 0 |
| `tests/keyboard.spec.ts` | 8 条路由：第一次 Tab 必须落在“跳到正文”跳转链接、焦点可见、可见可聚焦元素数 > 5、连续 Tab 能覆盖足够多的唯一元素 |
| `tests/address.spec.ts` | canonical / OG / JSON-LD / 旧入口链接；`/ming` 与尾斜杠 301；缺失资源 404；未知路径回退；根站与 `/gui/`、`/_next/` 不被接管 |
| `tests/journeys.spec.ts` | 四段可执行旅程：机构合作方生成一页简报、技术评估者筛选 VALIDATION、家庭用户只走公开入口、研究/写作者进入证据筛选 |
| `tests/mobile.spec.ts` | 8 条路由在 390 宽度无横向溢出 |
| `tests/render-check.mjs` | 独立的生产渲染检查（Chromium）：标题、H1、canonical、图片、console、failed request、手机溢出 |

### 2.2 24 个跳过项的构成

| 数量 | 位置 | 原因 |
| --- | --- | --- |
| 8 | WebKit 的“键盘顺序与焦点可见” | Playwright 自带 WebKit 构建只把表单控件放进 Tab 序列，链接不进入；原生 Tab 顺序无法在该构建中执行 |
| 16 | Chromium 与 Firefox 的“WebKit 跳转链接可用性” | 这是 WebKit 的替代检查，只在 WebKit 运行 |

WebKit 替代检查仍然验证：DOM 中第一个可聚焦元素是“跳到正文”跳转链接、程序化聚焦后可见且有轮廓、按 Enter 后跳到 `MAIN#main`。Chromium 与 Firefox 的原生 Tab 断言没有放宽。

### 2.3 稳定性处理（如实记录）

- Firefox 在并行运行时出现过两类不稳定：首页 axe 在 45 秒超时（单独复跑 4.5 秒通过；例外信息为 `RenderCompositorSWGL failed mapping default framebuffer`），以及首页第一次 Tab 落在 `BODY`（`workers: 3` 时复现）。两者都不是页面断言失败。最终把 Firefox 项目设为 `workers: 1`，并让它依赖其余四个项目、在它们完成后独占运行；全量复跑 93 通过、24 跳过、0 失败，用时 5.3 分钟。该处理只改变调度，没有放宽任何断言。
- WebKit 首页曾因“瞬间滚到底”导致懒加载图片未完成；改为逐屏滚动 + 轮询等待后通过。这是测试方法问题，不是页面缺陷。
- 全量日志中 93 个 `ok`、24 个 `-`、0 个 `failed`，逐项可在证据文件中检索。

## 3. nginx 1.28.0 子路径测试

命令：`bash nginx-test/run.sh`（Windows 本机 nginx 1.28.0；Linux/Docker 执行同一脚本）
原始输出：[`evidence/nginx-test-output.txt`](evidence/nginx-test-output.txt)

结果：

```text
51/51 passed, 1 skipped
```

- 52 项检查 = 33 项基线 + 19 项边界/回滚。
- 基线 33 项：8 条路由、7 条尾斜杠 301、`/ming` 无尾斜杠 301、6 个资源、3 个缺失资源 404、未知路径回退、4 项根站隔离、canonical/相对路径/OG。
- 边界 19 项：额外媒体资源、HEAD、查询串、`index.html`、资源目录、嵌套缺失索引、深层路径、前缀相似路径、大小写 `/MING/`、原始与编码路径穿越（直接 socket）、双斜杠、路由子路径、跳转保留查询串、HEAD 缺失资源、回滚目标的 `/ming/`、`/ming/ecosystem`、`/`。
- 唯一跳过项：`/MING/` 大小写检查在 Windows 大小写不敏感文件系统上无法成立，脚本按平台跳过；该检查由 Linux CI 执行，本报告不把它记为已通过。
- 回滚目标服务器只保留根站 SPA fallback；移除 `/ming/` 规则后，`/ming/` 必须回到 Self Space 哨兵页面，三项检查均通过。这证明规则是“新增前缀”，不是替换根站。
